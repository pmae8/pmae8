### What I'm building

**[FinanceHub](https://financehubs.vercel.app/)** &nbsp;·&nbsp; the biggest thing I've built. An AI-powered personal finance tracker.<br>Expenses, income, budgets, savings goals, net worth, subscriptions, and debt payoff using Snowball and Avalanche strategies &mdash; plus AI insights from an in-app assistant. No bank sync needed.<br>React + TypeScript + Vite + Tailwind on Supabase/Postgres, packaged for Android with Capacitor. 25 screens, 197 database migrations.<br>→ [**Open the live app**](https://financehubs.vercel.app/)

**[Femme Fast](https://femmefast.vercel.app/)** &nbsp;·&nbsp; her wellness, on her schedule. A wellness app for phone and web.<br>Intermittent fasting, pill alarms that actually ring on Android, cycle tracking, weight journey and activity tracking &mdash; one private app.<br>React Native for mobile. I ship the Android builds myself, with an in-app updater that reads a release manifest.<br>→ [**Open the live app**](https://femmefast.vercel.app/) &nbsp;·&nbsp; [releases and update manifest](https://github.com/pmae8/femme-fast-releases)
